# legacy/

The original student project: a PHP/CodeIgniter 3 online shop with a Bootstrap storefront and an
admin panel, kept as a reference for the rewrite in the parent folder. It is not part of the
running application and is not maintained.

Only the application code of the old project is kept here (`application/`, `index.php`,
`.htaccess`). The CodeIgniter framework, its user guide, the admin theme, the rich-text editor and
the product photos are not included.
