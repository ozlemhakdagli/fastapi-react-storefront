# legacy/

The original student project: a PHP/CodeIgniter 3 online shop with a Bootstrap storefront and an
admin panel, kept as a reference for the rewrite in the parent folder. It is not part of the
running application and is not maintained.

Only the code that the student wrote is kept: the controllers, models and views in `application/`,
the three configuration files that were changed (`config.php`, `database.php`, `routes.php`) and the
`.htaccess` rewrite rules. Everything that came unchanged with CodeIgniter 3.1.5 (the framework, its
user guide, the default configuration files, the error templates and the front controller), the admin
theme, the rich-text editor and the product photos are not included. The folder cannot run as a
site; it is there to be read.
